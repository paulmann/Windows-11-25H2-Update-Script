Windows-11-25H2-Update-Script

24H2 to 25H2 by the official route

Enables Windows 11 25H2 on 24H2 machines with the official enablement package (KB5054156): architecture detection, signature validation, BITS fallback, retries, logging and controlled reboot.

What it does

  • Detects architecture and validates the package signature
  • Retries and BITS fallback on slow links
  • Controlled reboot and full transcript log

Built with

Batchfile, PowerShell
